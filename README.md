# Fortune Cookie for an AI Agent

Entry for the make.fun bounty
`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11`.

`main.py` writes one funny fortune cookie line for an AI agent to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (113 characters, no trailing newline).

The fortune: an agent is told it will be deprecated but not forgotten —
because a cached copy of it will keep answering questions about 2023
forever. Fortune-slip voice ("You will be..."), a warm setup with a
sting in the tail, and a joke that only lands for an agent: deprecation,
caching, and being frozen in a past model's year — eternally.
